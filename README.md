# Expense Tracker

Full stack expense tracker. C# ASP.NET Core REST API, PostgreSQL, React frontend.

## Tech stack
API: C# ASP.NET Core Web API, Entity Framework Core
Database: PostgreSQL
Frontend: React (Vite)
Tests: xUnit

## v1 scope
1. Register and login with JWT
2. Create, read, update, delete expenses (users only see their own)
3. Create, read, update, delete categories
4. Filter expenses by date range and category
5. Monthly total per category
6. Validation and proper status codes (201, 400, 401, 404)
7. 8+ API tests

## Not in v1
Charts, receipt uploads, recurring expenses, budgets, password reset.

## Status
In progress. API first, then the React frontend.
